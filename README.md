# 模擬市議員｜巷口，開始 v13.8.0

這是以臺北文山木柵街區意象製作的虛構市議員選戰模擬原型。你安排競選行動、和合成居民交談，再看一場簡化的模擬開票。人物、居民、遭遇、候選人和選舉結果皆為虛構；遊戲數值不是現實民調、選舉預測或競選建議。

## 開始遊玩

需要 Node.js 18 或 Python 3，不需安裝 npm 套件，也不需帳號、API 金鑰或雲端服務。

在 macOS 可雙擊 `start.command`。也可以在專案資料夾執行：

```sh
npm start
```

或使用 Python：

```sh
python3 -m http.server 4173 --bind 127.0.0.1 --directory dist
```

接著開啟 <http://127.0.0.1:4173>。伺服器只接受本機連線，終端機視窗須保持開啟；按 Control-C 停止。遊戲存檔留在目前瀏覽器的本機儲存空間，不會隨程式檔案一起分享。

## 目前玩法

- 一局 30 天、9 回合，三幕各 3 回合；第 7 回合政見發表會，第 8–9 回合可催票。每回合只有一個主要行程。
- 選身分與政黨時可先安排第一回合拜訪、研究或直播，開始後可再調整行程。由拜訪、研究與曝光累積不同成果，不再要求選沒有實際效果的打法標記。
- 第 4 回合當天出現撞期邀約：去地方小隊成立會，從下回合開始有人沿用你的公開政見拉票；或去免費指定議題專訪，錯過地方成立會。兩邊都不去，也會失去這次機會。
- 準備過的具體政見在節目、直播或政見會得到正面迴響，會帶來下一回合的接續直播邀約。要占用一回合把握，過期就消失；連續上電視的觸及會降低。
- 準備過且已公開的具體立場會自動沿用；可在出發前選「這次重新表態」。首次回答、新研究、保證與對手質疑仍需選擇。
- 回答後直接進入下一回合；右側保留雙方上回合的行動、原話、觸及與後果，完整結果可展開。「你的回答」與助手、對手、事件等回合合計分開呈現。
- 合作、撞期與需要回應的質疑直接出現在右側；地圖提示首次選地點後消失。結局列出實際公開的最多三項最近政見與改口紀錄。
- 助手研究、直播與募款攤共用人力，顯示實際分工；超額舊選擇須先調整才能出發。
- 本人及助手研究先收合，議題保持固定順序；已完成及本人正在研究的題目留在原位並禁用。黑料從檔案選發布管道即可出發，發布結果保留供回看。
- 身分、出身、政黨、里長、合作條件、天氣與每局議題局面沿用既有規則。小馬有偏好打法，並根據你的支持情況選目標。
- 新玩法規格與檢查範圍見 [CAMPAIGN_ROUTES.md](CAMPAIGN_ROUTES.md)。`GAME_DESIGN.md` 與下列舊版紀錄保留設計背景；目前細節以實際引擎與最新需求為準。

## 舊版紀錄

## v12.1.0

- 三種開局身分取代原本的背景：全新素人、政二代、現任議員，各有不同的錢、起始支持、可信度與一條特殊規則。
- 合作約定改成第 2 或第 3 回合的邀約，當回合由玩家接受或婉拒；開局不再預選。
- 團隊預設派一位夥伴查資料，可調整人數；人數越多，同一回合依民調熱度查越多議題。主角準備政見時，其餘夥伴改去街訪。
- 還沒選行動時，底部按鈕改為「選一個行動 ↓」；電視自動選題改挑民調最熱的議題。
- 平衡門檻新增一項：每種身分看局面的最佳當選率都不低於 60%，彼此差距不超過 20 個百分點。

## v12.0.0

- 議題局面：每局隨機的議題熱度與做法偏好，只在合成選民層級產生，不與地點、背景、政黨或真實群體綁定。
- 研究分兩級：助手當回合查到多數偏好或「兩邊接近」；主角親自準備看到比例，可信度 +3。
- 可信度與未兌現保證：方案、坦白、更正加分，空頭保證與改口扣分；開票前沒更正的保證會讓聽過的人流失。
- 對手預告與回應期限、選行動前的天氣預報、若現在開票的估計與當選線、因果回顧與開票關鍵因素。
- 平衡門檻 `npm run test:balance`：不看局面的固定路線、看局面的打法、不同路線與隨機遊玩的當選率都有上下限，已併入 `npm test`。
- 助手街訪的觸及遞減改為每人各自計算；街訪議題限於該地點的話題。v11 舊版入口與存檔 key 保留於 `dist/legacy-v11/`。

## v11.0.0

- 首次導覽說明勝負、資金與回合流程；各背景提供附官方來源的政黨預設，官方主題與遊戲規則分開標示，所有背景都可覆寫同一組虛構約定。
- 居民有個別對話感受；約定衝突只對實際接觸者產生差異化回應，並與支持傾向及抽樣民調分開呈現。
- 新增廟前廣場、單一情境式重玩，以及展示已結算結果、可略過的四秒開票。v11 儲存資料與 v10.3 分開，v10.3 舊版入口及 key 保留於 `dist/legacy-v10-3/`。

## 目前限制

遊戲以 1,000 名合成選民、19 名虛構候選人和 13 席作縮小演算；只有一位主要對手會採取行動，其他候選人只參與計票。新玩法目前是一個固定時間的撞期事件加上後續資產／邀約，用來驗證「計畫、取捨、後果」是否有趣。尚未完成真人趣味與五分鐘計時驗收，完整策略平衡門檻也尚未通過；不以通過功能測試代替這兩項判斷。

## 專案內容

- `dist/`：遊戲 HTML、CSS、JavaScript、原創向量場景，以及保存的舊版入口。
- `scripts/serve.cjs`、`start.command`：本機啟動工具。
- `tests/`：引擎、介面接線、平衡門檻（`strategy-balance.cjs`）和匯出完整性測試。
- `package.json`：本機啟動與測試指令。
- `VERSION.txt`：遊戲版本。
- `FILE_LIST.txt`、`SHA256SUMS.txt`：發布檔案清單與 SHA-256 校驗值。

目前版保留霧面玩具風 WebP 場景與原創 SVG 風格切換；頁面沒有外部字型或圖片下載。遊戲內背景資料會連到相關的官方來源頁面，只有使用者點擊時才會開啟。

此 repo 以 v10.1.0 遊戲匯出包為基礎；v10.2.0 加入一鍵新局，v10.3.0 改善結局重玩入口，v11.0.0 加入來源化背景、居民反應、廟前廣場、單一重玩及四秒開票，v12.0.0 加入議題局面、可信度、對手預告與期限、天氣預報和因果回顧。v11 與 v10.3 舊版分別保留於 `dist/legacy-v11/`、`dist/legacy-v10-3/`，本機啟動方式與未指定授權狀態維持不變。清單與校驗值依本次發布內容產生。

## 測試

```sh
npm run test:quick
npm test
```

歷史紀錄：v12.1.0 的 `npm test` 通過：v12 引擎 17,859 項檢查、v12 介面 255 個 DOM 斷言、保留的 v11 與 v10 回歸套件，以及平衡門檻 `npm run test:balance`（約 3 分鐘；種子 1–300 中，不看局面的最佳固定路線 42%，看局面的最佳打法 85.3%，完全隨機 5.7%；三種身分的最佳當選率 85.3%–94.7%）。這些自動驗證不代表真人五分鐘遊玩已完成；瀏覽器在 1366×900 與 375×812 走過一局。
