# 模擬市議員｜巷口，開始 v10.3

這是以臺北文山木柵街區意象製作的虛構市議員選戰模擬原型。你安排競選行動、和合成居民交談，再看一場簡化的模擬開票。人物、居民、遭遇、候選人和選舉結果皆為虛構；遊戲數值不是現實民調、選舉預測或競選建議。

## 開始遊玩

需要 Node.js 18 或 Python 3，不需安裝 npm 套件，也不需帳號、API 金鑰或雲端服務。

在 macOS 可雙擊 `start.command`。也可以在專案資料夾執行：

```sh
npm start
```

或使用 Python：

```sh
python3 -m http.server 4173 --bind 127.0.0.1 --directory dist
```

接著開啟 <http://127.0.0.1:4173>。伺服器只接受本機連線，終端機視窗須保持開啟；按 Control-C 停止。遊戲存檔留在目前瀏覽器的本機儲存空間，不會隨程式檔案一起分享。

## 玩法

- 目標約五分鐘玩完一局並快速重試；五分鐘目前是設計目標，尚未做真人計時驗收。
- 結局摘要旁提供大型「新的一局」按鈕，主要操作列固定在可捲動正文外（手機固定在底部）；按下後立即換一個虛構情境、取代當前進度並進入第 1 回合，不需要備份、確認或再次按開始；初始助手月薪只扣一次。
- 一局有 30 天、10 個三日回合。每回合安排一個主要行動：準備政見、街訪、上節目、募款或擴充團隊。
- 選擇拜訪地點與團隊分工；居民會記得先前對話，遇到新資料或待回應事項時再作答。
- 查看回合回顧、虛構民調和最終開票。這些結果只由遊戲內的簡化規則計算。
- 完整玩法、資金規則、情境來源與設計限制見 [`GAME_DESIGN.md`](GAME_DESIGN.md)。

## 目前限制

遊戲以 1,000 名合成選民、19 名虛構候選人和 13 席作縮小演算；目前只有一位主要對手會採取行動，其他候選人只參與計票。偏好模型和議題池均經簡化，也未實作完整法定席次保障、競選補貼或真正 3D 場景。完整瀏覽器與手機版面的操作尚未正式驗收。詳細限制和背景資料請見 [`GAME_DESIGN.md`](GAME_DESIGN.md)。

## 專案內容

- `dist/`：遊戲 HTML、CSS、JavaScript、原創向量場景，以及保存的舊版入口。
- `scripts/serve.cjs`、`start.command`：本機啟動工具。
- `tests/`：引擎、介面接線和匯出完整性測試。
- `package.json`：本機啟動與測試指令。
- `VERSION.txt`：遊戲版本。
- `FILE_LIST.txt`、`SHA256SUMS.txt`：發布檔案清單與 SHA-256 校驗值。

目前版遊戲素材以程式碼繪製的 SVG 方塊人物與場景為主；頁面沒有外部字型或圖片下載。遊戲內背景資料會連到相關的官方來源頁面，只有使用者點擊時才會開啟。

此 repo 以 v10.1.0 遊戲匯出包為基礎，v10.2.0 加入一鍵新局與回歸測試；v10.3.0 將新局入口加到結局摘要旁及固定的主要操作列。既有遊戲規則、舊版入口與本機啟動工具均保留。清單與校驗值依本次發布內容產生。

## 測試

```sh
npm run test:quick
npm test
```

測試使用 Node.js 內建模組。自動測試涵蓋引擎規則、最小介面接線和檔案完整性，不代表完成真人瀏覽器試玩或完整行動裝置版面驗收。
